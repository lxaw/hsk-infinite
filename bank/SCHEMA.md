# Question bank schema (all levels)

One JSON file per part. Each file holds an array of **units**. A unit is the thing the
generator samples: for most parts that is one question, for grouped parts it is a whole
passage / word-bank block with several questions.

Common fields on every unit: `id` (unique, e.g. `L1-0001`), `lesson` (1–20 or null),
`topic` (short tag). Speakers in audio: `"m"` man, `"f"` woman, `"n"` narrator.

| File | Exam Qs | Unit shape |
|---|---|---|
| `L1.json` | 1–10 true/false | `{passage, speaker, statement, answer: true/false}` |
| `L2.json` | 11–25 short dialogue | `{dialogue:[{s,t},{s,t}], question, options[4], answer: 0-3}` |
| `L3a.json` | 26–35 long dialogue | `{dialogue:[{s,t}×4-5], question, options[4], answer}` |
| `L3b.json` | 36–45 passage (2 Qs) | `{passage, speaker, questions:[{question, options[4], answer}×2]}` |
| `R1.json` | 46–55 word bank | `{kind:"sentence"|"dialogue", bank[6], example:{text, answer}, items:[{text, answer}×5]}` — blanks written `（ ）`; dialogue lines prefixed `A：`/`B：` |
| `R2.json` | 56–65 order ABC | `{A, B, C, answer:"BAC"}` — exactly one valid order |
| `R3a.json` | 66–79 short passage | `{passage, question, options[4], answer}` |
| `R3b.json` | 80–85 passage (2 Qs) | `{passage, questions:[{question, options[4], answer}×2]}` |
| `W1.json` | 86–95 arrange words | `{pieces[], answer, accepted[]}` — `accepted` lists every other grammatical order |
| `W2.json` | 96–100 picture + word | `{word, scene, image, models[3]}` — `scene` is the image prompt; `models` are sample answers |

Answers for options are 0-based indexes. Audio for listening units is generated by
`tools/build_audio.py` into `site/audio/<id>.mp3`; images by `tools/build_images.py`
into `site/images/<id>.png`.

## Generic part types (levels/<level>.json `type`)

The tables above describe HSK 4. All levels use the same unit shapes by part `type`:

| type | Unit shape |
|---|---|
| `tf` | `{passage, speaker, statement, answer: bool}` |
| `mcq` | listening: `{dialogue[] or passage+speaker, question?, options, answer}`; reading: `{passage?, question?, options, answer}`. Parts with `noQuestion` omit the question (HSK 5 R2, HSK 6 L1/R1/R2). Blanks in a passage are `[1]`, `[2]`… (HSK 6 R2: options are word tuples separated by full-width spaces). 病句 items add `errorType` and `explain`. |
| `mcq_group` | `{passage or dialogue, speaker?, title?, questions:[{question?, options, answer}]}`. With `cloze: true` the passage holds `[1]..[n]` and questions have no text (HSK 5 R1). Size must be in the part's `questionsPerUnit`. |
| `wordbank` | HSK 4 R1 (see above) |
| `insert` | `{passage with [1]..[5], sentences[5], answers[5]}` — answers[k] = index of the sentence for blank k (HSK 6 R3) |
| `order` | HSK 4 R2 |
| `arrange` | `{pieces[], answer, accepted[]}` |
| `free` | by part `kind`: `picture_sentence {word, scene, models[]}`, `essay_words {words[5], model}`, `essay_picture {scene, model}`, `summary {title, story (~1000 chars), model}` |

Speakers: `m`, `f`, `n` (narrator), plus `m2`/`f2` for a second man/woman.

## HSK 3.0 levels (新HSK 4, 5, 6, 7–9)

The new-format levels reuse the types above with a few additions (set in `levels/<level>.json`):

| Where | Addition |
|---|---|
| `mcq_group` question | A question without `options` is a short written answer: `{question, answer, accepted[]}` (the part may set `maxAnswerChars`); `spoken` is the form read aloud for a listening fill-in whose printed `question` shows a blank. Part flags: `printQuestions`, `silentQuestions` (statements are printed, not read), `judge` + `optionCount: 3` (新HSK 7–9 part 1: √ / × / 〇, with `keepOrder` on each question). |
| `insert` | `distractors: 1`: `sentences` has one more entry than `answers`. `ordering: true`: the passage is only the chain `[1] → [2] → …`; in 新HSK 7–9 the chain contains `〔已给出〕` and the given paragraph follows the chain. |
| `wordbank` | no `example`; the sixth word is a distractor. |
| `free` kinds | `essay_topic {task, model}`, `picture_story {task, scenes[4], model}` (tiled 2×2 into one picture), `practical {task, model}`, `chart_essay {task, chart, model}` (`chart`: `{type: bar\|barh\|pie\|line, title, labels, values or series, unit}`, drawn by `tools/build_charts.py`), `translation {source, model}`. |
| speaking parts (`speaking.parts`, not scored) | `repeat {speaker, text}`; `picture_talk {scene or scenes[4], model}`; `answer {task, model, material?, source?}` (part flag `silent`: the task is not read aloud); `listen_answer {speaker, text, model}` or, with several questions on one recording, `{speaker, text, questions:[{question, seconds, model}]}`. |
